# Esquemas SQL

Este repositorio contiene esquemas utilizados para SQL por el curso de Base de Datos, cátedra Román. Se recomienda fuertemente tener instalado [Docker](https://docs.docker.com/get-started/get-docker/) y [docker-compose](https://docs.docker.com/compose/install/) para su correcto uso.

Se adjunta un [tutorial para configurar Docker](https://www.youtube.com/watch?v=uK6tZg_s_HA&list=PLuHhZ3tdB69DiCpSc66w4Yrf2aXnLTcP3). Ante cualquier consulta, por favor enviarnos un mensaje al canal de soporte-tecnico en Slack.
